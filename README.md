# 💀 مــنـصــة شــبــح | SHABAH NEON PLATFORM

منصة تواصل تفاعلية حية تعمل كـ **Telegram Mini App** مدعومة ببوت تلجرام عبر توكن، تتميز بتصميم سيبراني نيون مظلم وشعار الجمجمة المتوهجة واسم **«شبح»**. تتيح للمستخدمين التواصل المباشر مع المطور، إرسال بصمات صوتية وصور فورية، وطلب اتصال حقيقي (صوت وكاميرا WebRTC) مع ميزة إخفاء هوية المطور بالكامل (Stealth Mask Mode)، ولوحة تحكم متطورة للمطور لإدارة المكالمات وميزات الإشراف الفوري (**حظر 🚫، كتم 🔇، طرد ⚡**).

---

## ⚡ أبرز المميزات

1. **تصميم نيون سيبراني فريد (Cyberpunk Neon)**:
   - جمجمة سيبرانية متوهجة ومتحركة تتفاعل مع الحالة والصوت.
   - تأثيرات مسح الشاشة (CRT Scanlines)، إضاءات نيون (Cyan & Neon Pink)، وأزرار تفاعلية.
   - متوافقة 100% كـ تطبيق مصغر داخل تطبيق تلجرام الرسمي (Telegram Mini App) للآيفون والأندرويد والكمبيوتر.

2. **بوت تلجرام متكامل (Telegram Bot API)**:
   - رد فوري على أمر `/start` مع بطاقة ترحيب نيون وزر مباشر لفتح المنصة.
   - إرسال تنبيهات فورية لحساب المطور في تلجرام عند دخول زائر جديد أو طلب مكالمة.

3. **مراسلة حية ووسائط مباشرة**:
   - شات مباشر وفوري بتقنية WebSockets.
   - **بصمة صوتية**: تسجيل صوتي مباشر مع مؤقت وموجات صوتية ومشغل صوت أنيق.
   - **صورة مباشرة**: التقاط مباشر من الكاميرا وإرسال فوري إلى المطور، أو رفع صورة من المعرض.

4. **اتصال حقيقي WebRTC (صعود مايك أو كاميرا)**:
   - صوت وفيديو بجودة عالية وبدون تأخير عبر بروتوكول WebRTC و STUN Servers.
   - نظام طلب اتصال: الزائر يطلب صعود مايك أو كاميرا، ويصل إشعار رنين للمطور للقبول أو الرفض.
   - عناصر تحكم بالمكالمة: كتم/تفعيل المايك، إيقاف/تفعيل الكاميرا، وإنهاء المكالمة.

5. **إخفاء هوية المطور بالكامل (Stealth Ghost Mask)**:
   - يظهر المطور دائماً للزوار تحت اسم **«شبح»** وشعار الجمجمة فقط.
   - في مكالمات الفيديو: ميزة **قناع شبح** تستبدل كاميرا المطور بجمجمة نيون متحركة تتحدث مع الزائر، مما يتيح للمطور رؤية وسماع الزائر بينما تظل هويته وشكله مخفيين بنسبة 100%!

6. **لوحة تحكم وإشراف صارمة للمطور**:
   - رابط سري محمي بكلمة مرور: `/ghost-admin?secret=...`
   - عرض فوري للزوار المتصلين بالمنصة.
   - أزرار سريعة لكل مستخدم:
     - **كتم (Mute)**: تعطيل قدرة المستخدم على إرسال الرسائل أو البصمات الصوتية.
     - **طرد (Kick)**: إنهاء جلسة المستخدم فوراً وقطع اتصاله والمكالمة.
     - **حظر (Ban)**: حظر المستخدم نهائياً من دخول المنصة أو استخدام البوت وحفظ حالته.

## 🚀 طريقة التثبيت والتشغيل المحلي

### 1. المتطلبات الأساسية
- مثبت لديك **Python 3.10+**.

### 2. تثبيت الحزم
افتح موجه الأوامر داخل مجلد المشروع ونفذ:
```bash
pip install -r requirements.txt
```

### 3. ضبط الإعدادات وملف البيئة
قم بإنشاء ملف باسم `.env` بجانب ملف `.env.example` وضع فيه الإعدادات الخاصة بك:
```env
# 1. توكن بوت تلجرام من @BotFather
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# 2. الآيدي الرقمي لحسابك في تلجرام (احصل عليه من @userinfobot)
DEVELOPER_ID=123456789

# 3. كلمة سر لوحة تحكم المطور
ADMIN_SECRET_KEY=shabah_secret_2026

# 4. الرابط بعد الرفع (أو اتركه محلياً أثناء التجربة)
WEBAPP_URL=http://localhost:8000
```

> **ملاحظة**: يمكنك تشغيل المنصة مباشرة حتى قبل وضع التوكن، وستعمل الواجهة ولوحة التحكم محلياً!

### 4. التشغيل بنقرة واحدة
- على نظام Windows: اضغط مرتين على ملف `run.bat`.
- أو عبر التيرمينال:
```bash
python main.py
```

- افتح واجهة المستخدم: `http://localhost:8000`
- افتح لوحة المطور السرية: `http://localhost:8000/ghost-admin?secret=shabah_secret_2026`

## 🤖 ربط المنصة ببوت تلجرام (Telegram Mini App)

1. افتح بوت **@BotFather** على تلجرام.
2. أرسل `/newbot` وأنشئ بوتاً جديداً وانسخ الـ **Token** وضعه في `.env`.
3. لتفعيل زر الـ **Menu Button** كتطبيق Mini App في البوت:
   - أرسل لـ @BotFather الأمر: `/setmenubutton`
   - اختر البوت الخاص بك.
   - اكتب عنوان الزر، مثلاً: `💀 دخول شبح ⚡`
   - ضع رابط منصتك المنشورة (يجب أن يكون `https://`).

## 🌐 رفع واستضافة المنصة مجاناً (Render / Railway)

لكي تعمل كاميرا الويب والمايكروفون وميزات Telegram WebApp بكفاءة خارج شبكتك المحلية، يلزم رابط مشفر **HTTPS**:

### النشر المجاني عبر Render.com:
1. ارفع المشروع إلى حسابك في **GitHub** (راجع الخطوات أدناه).
2. ادخل على [Render.com](https://render.com) وأنشئ حساباً مجانياً.
3. اضغط على **New +** ثم اختر **Web Service**.
4. اربط مستودع GitHub الخاص بهذا المشروع.
5. في إعدادات الخدمة:
   - **Environment**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python main.py`
6. في قسم **Environment Variables** أضف:
   - `BOT_TOKEN`: توكن البوت الخاص بك.
   - `DEVELOPER_ID`: آيدي حسابك في تلجرام.
   - `ADMIN_SECRET_KEY`: كلمة سر اللوحة.
   - `WEBAPP_URL`: رابط موقعك الذي سيوفره Render (مثال: `https://shabah-neon.onrender.com`).
7. اضغط **Deploy Web Service**، وخلال دقيقة ستكون منصتك نشطة عالمياً برابط HTTPS مجاني!
